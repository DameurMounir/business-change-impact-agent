# Project boundary

The product answers one question: **What changes directly and indirectly?**

It may identify and trace evidence-backed impacts, propose bounded assessment
obligations, record a local human review and export an audit packet. It may not
accept risk, approve funding, assign staff, select a vendor, change a production
system, communicate with customers or decide go-live.

All case content is synthetic. SQLite, when introduced, is a local demonstration
store rather than an enterprise governance database.
