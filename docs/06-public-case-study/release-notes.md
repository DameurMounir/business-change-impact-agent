# Business Change Impact Agent v0.1.0

First complete public release of the six-milestone synthetic AtlasBridge case study.

## Included

- frozen eight-component change package and evidence manifest;
- 77-entity, 166-relationship typed business graph;
- deterministic direct, indirect, conditional and explicitly unaffected classification;
- canonical evidence-linked paths, collisions, attention reasons and obligations;
- fail-closed candidate-path and adapter verification;
- local CLI and Streamlit Impact Room;
- SQLite digest-bound review, nonce controls and hash-linked event ledger;
- equivalent JSON, Markdown and safe HTML exports;
- evaluator-isolated frozen-case metrics and adversarial results;
- Python 3.12/3.13 CI, security and package release gate;
- visual README, case study and demonstration script.

## Verified frozen-case observations

36 direct impacts, 12 indirect impacts, three conditional impacts, six explicitly unaffected entities, 22 collisions, five standard blocked claims and 53 proposed obligations.

## Boundaries

The organisation and data are fictional. Perfect evaluator agreement measures the committed deterministic contract only. Live-model evaluation is `NOT_RUN`. No production deployment, implementation, budget, staffing, vendor, risk-acceptance or go-live decision is included.
