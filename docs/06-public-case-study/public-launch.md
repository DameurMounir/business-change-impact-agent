# Public launch copy

## LinkedIn / portfolio post

A process redesign is not complete when the new diagram looks cleaner. The real question is what changes across roles, systems, data, controls, communications, suppliers and operating obligations.

I built **Business Change Impact Agent** as a public, synthetic case study that answers: **What changes directly and indirectly?**

The repository traces eight authorised onboarding changes through an evidence-linked business graph, separates direct from indirect and conditional impacts, identifies collisions, blocks unsupported paths and requires digest-bound human confirmation before export.

The key engineering choice is authority separation: the analysis can propose an impact packet, but it cannot approve implementation or go-live.

Frozen-case result: 36 direct, 12 indirect, three conditional, six explicitly unaffected, 22 collisions and five blocked candidate claims. These are reproducible synthetic-case observations, not claims of general AI accuracy.
