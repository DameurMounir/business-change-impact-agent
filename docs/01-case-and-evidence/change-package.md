# Authorised change package

The frozen package contains exactly eight components:

1. Reusable intake record
2. Accountable case owner
3. Parallel independent checks
4. Dedicated exception lane
5. Evidence-bound activation
6. Automated applicant notifications
7. Controlled pilot guardrails
8. Operational observability

The package also records six explicitly unaffected negative controls. An
explicitly unaffected result is evidence-backed and is not interchangeable with
"no supported impact found".
