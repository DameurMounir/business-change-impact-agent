# Security Policy

## Supported version

The current `0.1.x` line receives security corrections.

## Reporting

Report vulnerabilities privately through the repository owner's GitHub contact
route. Do not publish exploit details, credentials or personal information in a
public issue.

## Security boundary

This project is a local, synthetic demonstration. It does not provide identity
verification, enterprise authentication, legal signatures, production access
control, risk acceptance, change execution or go-live authority. Evidence files
are treated as untrusted data. Runtime code must not read the evaluation answer
key.
