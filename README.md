# Business Change Impact Agent

> **Decision question:** What changes directly and indirectly?

This repository is being built as a controlled, synthetic public business-analysis proof. It will trace an authorised change package through typed business relationships, separate direct from indirect and conditional impact, preserve evidence gaps, and require human confirmation before a packet is confirmed.

The project does not deploy software, modify production systems, allocate people or budget, accept risk, or decide go-live.
