# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-07

### Added

- frozen AtlasBridge synthetic change package, evidence and typed graph;
- deterministic impact rulebook and canonical traversal engine;
- provider-neutral adapter boundary with fail-closed verification;
- CLI, Streamlit Impact Room, SQLite review protocol and hash-linked ledger;
- JSON, Markdown and safe HTML equivalent exports;
- evaluator-isolated metrics, adversarial tests and complete release gate;
- visual public case study, diagrams and five-minute demonstration script.

### Boundaries

- no production data or deployment;
- no live-model evaluation;
- no implementation, financial, staffing, vendor, risk-acceptance or go-live authority.
